# Contributing

Bug fixes and documentation improvements are welcome. For new **tasks**, MDP
changes, or paper reproductions, [open an issue](https://github.com/wbc-mjlab/wbc-mjlab/issues)
first.

**Full guide:** https://wbc-mjlab.github.io/wbc-mjlab/source/contributing.html

## Quick workflow

1. Fork, branch from `main`, keep PRs focused.
2. `make sync` then `make check` (lint + smoke).
3. Link the issue: `Closes #N`.
